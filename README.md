# UTD Macro V2

Ultimate Tower Defense macro hub for Roblox: Linoria UI, recording/replay, map-aware auto replay.

## Raw script

https://raw.githubusercontent.com/fayysterlyy/utd-macro-v2/main/utdV2.luau

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/fayysterlyy/utd-macro-v2/main/utdV2.luau"))()
```

The script is updated here after every change. The in-script **Reexecute** toggle pulls the latest version after a teleport.

## Obsidian UI build (utd_obs)

Same macro, UI layer swapped from Linoria to [Obsidian](https://github.com/deividcomsono/Obsidian) (a Linoria fork - no source patches needed). Logic is byte-identical to `utdV2.luau` apart from the UI calls; use whichever UI you prefer.
